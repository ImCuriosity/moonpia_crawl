# 분석 결과 (집계값만)

2026-07-27 기준. 작품 389건 · 회차 10,845건 · 댓글 95,125건 · 고유 작성자 16,580명으로
학습한 결과입니다. `python -m munpia.cli train` 이 만든 산출물 중 **개인 식별 정보가
없는 것만** 골라 담았습니다.

원본 수집 데이터(`data/`)는 댓글 작성자의 닉네임과 회원 식별자(`blogUrl`)를 포함하므로
저장소에 올리지 않습니다. `user_churn_predictions.csv` 도 `user_key` 컬럼 때문에
여기서 제외했습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `*_factor_rank.csv` | **이탈 요인 순위** — 그 요인을 섞었을 때 ROC-AUC가 얼마나 떨어지는가 |
| `*_cv_scores.csv` | 모델별 교차검증 성능 (ROC-AUC · PR-AUC · Brier) |
| `*_explain.csv` | 로지스틱 계수와 오즈비 (표준화 피처 기준) |
| `*_predictions.csv` | 회차·작품별 이탈 확률 (독자 단위는 개인정보라 제외) |
| `*_summary.json` | 라벨 정의 · 피처 목록 · 표본 수 · 교차검증 설정 |

`episode` = 회차 단위 · `user` = 독자 단위 · `novel` = 작품 간 비교

## 읽을 때 주의할 것

1. **`0과구분` 판정 없이 순위만 읽지 마세요.** 중요도가 표준편차의 2배를 넘어야
   우연이 아니라고 말할 수 있습니다. `novel` 태스크는 1~9위 전부 미달입니다.

2. **중요도는 상관이지 인과가 아닙니다.** 반응 구성비와 감정은 이탈과 같은 시점에
   관측된 값입니다. "불만 댓글이 이탈을 일으킨다"가 아니라 "이탈이 큰 회차에는
   불만 댓글이 많다"입니다.

3. **`churn_prob` 는 순위용입니다.** 확률 보정은 하지 않았습니다
   (`--class-weight none` 이 기본이라 크게 어긋나지는 않지만, 절대값으로 읽지 마세요).

4. **분석 범위는 무료 구간(1~25화)입니다.** 유료 회차의 `view_count` 는 무료 회차와
   다른 것을 세기 때문입니다 — 페이월 직후 조회수가 직전의 4.5%로 떨어지는 동안
   추천수는 93%, 댓글수는 100%가 유지됐습니다(10작품 전부).
